# Política de seguridad

Si encontrás una vulnerabilidad, **no abras un issue público**. Usá
[*Report a vulnerability*](../../security/advisories/new) en la pestaña Security de este repositorio
(aviso privado de GitHub). Incluí los pasos para reproducirlo y el impacto que esperás.

- Respondemos dentro de los 7 días.
- No pruebes contra instancias de otras personas ni con datos reales: usá `npm run demo` o tu propio proyecto de Supabase.
- El resumen de la revisión de seguridad está en [docs/SEGURIDAD.md](docs/SEGURIDAD.md).
